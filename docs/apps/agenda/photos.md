# Agenda — photos in task descriptions

- Add in the task form with one **Add Photo** button. On Android it opens the shared source sheet: **Take photo** (system camera; the picture stays in Agenda only, never in the phone gallery, and the temporary capture file is deleted after import) or **Choose from gallery** (system picker, several at once); Back/Cancel closes it. Desktop shows **Add Photo…** (GTK file chooser, no sheet). Shared design and mechanics: [../../components/photo-source.md](../../components/photo-source.md) (since 0.4.2).
- The webview scales each image to document quality: longest side ≤ 2400 px, WebP at quality 0.85 (both WebKitGTK and Android WebView encode WebP; JPEG is the fallback). EXIF orientation is applied.
- Rust (`photos.rs`) stores the bytes as `<data_dir>/agenda-photos/<id>.webp` (outside SQLite so the DB stays small) and a `photos` record with `file, mime, w, h, bytes, sha256, created_at`. Tasks list photo ids in `photos`.
- Details show the photos inside the notes card (grid). A photo can also be placed inline in the Markdown with `![caption](photo:<id>)`. Tap a photo for full screen; Back/Escape closes it. The viewer has **Save to gallery** (Android: `Pictures/Selfkit/Agenda`; desktop: **Save to Pictures** → `~/Pictures/Selfkit/Agenda`, Rust `photo_export`), confirmed by a toast.
- Removing a photo from a task keeps the file (undo stays possible). Not yet: cleanup of unused photo files, and syncing photo files between devices (planned via the S3 blob store; records already sync).
- Android camera: the manifest declares a `<queries>` entry for `IMAGE_CAPTURE`; no CAMERA permission is needed (the camera app takes the picture). `SelfkitPhotos.kt` (bridge `window.SelfkitPhotos`) cleans capture temp files and saves to the gallery.
- Code: `TaskForm.svelte` (`askPhotoSource`, hidden gallery + camera inputs, `cleanCaptures()` after import), `App.svelte` (mounts `PhotoSourceSheet`; `closePhotoSource()` first in `backAction`; toast layer raised to z-85 so the save toast shows over the viewer), `PhotoViewer.svelte`, `lib/photo-source.ts`.
